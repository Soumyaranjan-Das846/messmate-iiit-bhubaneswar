# MessMate – IIIT Bhubaneswar

### Mess Management System

MessMate is a full-stack web application developed to simplify and digitize mess management activities at IIIT Bhubaneswar.

### Tech Stack
- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

### Features
- Admin and Student Login
- Student Management
- Weekly Mess Menu
- Meal Management
- Expense Tracking
- Payments and Billing
- Feedback and Complaint Management
- Dashboard and Reports

### How to Run
1. Install Node.js and MongoDB.
2. Run `npm install` in both frontend and backend directories.
3. Configure the backend `.env` file using `.env.example`.
4. Start the backend using `npm start`.
5. Start the frontend using `npm run dev`.
6. Open `http://localhost:5173` in your browser.
